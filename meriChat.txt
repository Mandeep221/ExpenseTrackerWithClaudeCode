❯ What does this project do?                                                    

  Read 2 files (ctrl+o to expand)

⏺ This is a starter/skeleton project for a Flask expense tracker app — designed
  as a step-by-step coding exercise (likely for students or a workshop).

  What's built so far:
  - Landing page, login page, and registration page (UI only, no logic yet)
  - Flask app running on port 5001
  - Static CSS and JS files
  - Database module stub (SQLite, not yet implemented)

  What's planned (placeholder routes):
  - User auth: register, login, logout
  - User profiles
  - Expense CRUD: add, edit, delete expenses

  The db.py file is intentionally empty with comments guiding students to
  implement get_db(), init_db(), and seed_db() as Step 1. The route stubs
  reference Steps 3–9, suggesting a guided, incremental build-out.

❯ What tech stack does this project use?                                        

⏺ Based on the files already read:

  - Backend: Python + Flask (v3.1.3)
  - Database: SQLite (via Python's built-in sqlite3)
  - Frontend: HTML/Jinja2 templates, plain CSS, vanilla JavaScript
  - Testing: pytest + pytest-flask
  - Server: Flask dev server (Werkzeug v3.1.6)

  No ORM, no frontend framework, no external database — intentionally minimal
  stack.
